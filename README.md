# Co-op Capers: Summit

Two penguins tied by a rope climb a snowy mountain to the summit.
Local co-op on one keyboard, or online with invite codes.

## Controls

- Bread (P1): Q / D to move, Z to jump (AZERTY).
- QWERTY keyboards: switch the layout in the menu, keys become A / D / W.
- Fred (P2): Left / Right arrows to move, Up arrow to jump.
- R restarts the run. Touch pads appear on touch devices.

## Play

Open `index.html` (or `npm run serve`), pick Same screen, Host, or
Join. The host's level loads automatically for the guest.
